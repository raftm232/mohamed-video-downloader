# محمل الفيديو — محمد رأفت (واجهة بنفسجية + PWA)

## مميزات الواجهة
- تصميم بنفسجي مستقبلي بحركات خفيفة ومتجاوب مع الهاتف.
- اختيار فيديو مع صوت أو استخراج MP3، والجودة.
- ملفات PWA الأساسية لإتاحة خيار **إضافة إلى الشاشة الرئيسية** من المتصفح المتوافق.
- الخادم يعتمد Python وFlask وyt-dlp وFFmpeg.

## مهم جدًا: الموقع والتطبيق
- GitHub يحفظ الكود، لكنه لا يشغّل `app.py`.
- GitHub Pages يستطيع عرض الواجهة الثابتة فقط؛ زر التحميل يحتاج خادم Python منفصلًا.
- الـPWA يجعل الموقع يبدو كتطبيق عند تثبيته من المتصفح، لكنه **لا يحوّل Python تلقائيًا إلى تطبيق Android مستقل**. يجب أن يبقى الخادم متاحًا على الإنترنت أو على الهاتف.
- ملفات PWA هنا لا تحتوي على أيقونات متجر احترافية؛ يمكن إضافتها لاحقًا قبل النشر العام.
- لا تنشر خدمة تحميل عامة من دون مصادقة، تحديد معدل الطلبات، التحقق من الروابط ومنع الوصول إلى الشبكات الداخلية، وحدود أحجام/وقت. نسخة الخادم الحالية للاختبار المحلي.
- استخدمها فقط لتنزيل المحتوى الذي تملك حق تنزيله؛ لا تتجاوز DRM أو الفيديوهات الخاصة/المحمية.

## تشغيل على Termux (محليًا على الهاتف)
```sh
pkg update
pkg install python ffmpeg git
cd ~/mohamed-video-downloader
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
ثم افتح `http://127.0.0.1:8000`. افحص FFmpeg بالأمر `ffmpeg -version`. أوقف الخادم بـ `Ctrl+C`.

## رفع المشروع إلى GitHub
أنشئ مستودعًا جديدًا فارغًا على GitHub، ثم داخل مجلد المشروع:
```sh
git init
git add .
git commit -m "Purple Arabic video downloader PWA"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```
استبدل `USERNAME/REPOSITORY` بالقيم الحقيقية. لا ترفع كلمات مرور أو رموز دخول.

## تثبيت الواجهة كتطبيق من الهاتف
بعد نشر الواجهة عبر HTTPS، افتح الرابط في Chrome أو متصفح متوافق، ومن القائمة اختر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق** إذا ظهر الخيار. تثبيت الواجهة لا يعني أن التحميل يعمل: يجب أن يكون API متصلًا بخادم Python منشور وآمن.

## المتطلبات
- Python 3.10+
- `pip install -r requirements.txt`
- FFmpeg متاح في PATH
